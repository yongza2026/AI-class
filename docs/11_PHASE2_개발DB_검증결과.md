## 2. 적용한 구조

다음 7개 표를 추가했다.

- 품목: `inventory_items_v2`
- 단위 환산: `unit_conversions_v2`
- 구매 문서: `purchase_documents_v2`
- 구매 상세: `purchase_lines_v2`
- 실사 회차: `stocktake_sessions_v2`
- 실사 상세: `stocktake_lines_v2`
- 재고 원장: `inventory_ledger_v2`

모든 표에서 RLS가 켜진 것을 확인했다. 재고 원장에는 수정·삭제 정책과 권한을 주지 않아 추가 기록만 가능하다.

현재 앱을 개발 DB에서 바로 실행하기 위한 호환 표도 추가했다.

- 자료 묶음: `store_datasets`
- 자료 기록: `store_records`
- 가입 요청: `access_requests`

`store_records`는 현재 앱이 사용하는 16개 자료 종류를 모두 허용한다. 기존 화면이 호출하는 전체 저장 함수와 샘플 삭제 함수도 개발 DB에만 추가했다. 이 호환 계층은 현재 화면 검증용이며, 새 재고 기능은 위의 추가형 v2 표와 확정 함수를 우선 사용한다.
