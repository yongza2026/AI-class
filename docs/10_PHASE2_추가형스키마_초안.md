# PHASE 2 추가형 데이터 구조 초안

이 문서는 구현 방향을 검토하기 위한 초안이다. 운영 DB에는 적용하지 않았다.
2026-10-15에 별도 개발 프로젝트 `POCO Operations Dev`에만 추가형 구조를 적용해 검증했다.

## 1. 목표

- 기존 `store_records`와 샘플 자료를 그대로 둔다.
- 품목, 단위 환산, 구매 문서, 입고, 실사, 재고 이동을 전용 표에 추가한다.
- 조회할 때 계산 결과가 같도록 한 뒤, 기능별로 새 구조를 켠다.
- 잘못된 기록을 삭제·덮어쓰기보다 반대 방향 기록으로 취소해 이력을 남긴다.

## 2. 핵심 원칙

### 품목 ID는 유지한다

새 품목에는 DB용 UUID를 붙이되 현재 `materialId`를 `legacy_material_id`로 함께 보관한다. 화면과 자료 이관은 이 대응표로 연결한다.

### 모든 수량은 기준 단위로 저장한다

- 액체: ml
- 무게: g
- 개수: 개

예: 700ml 두 병을 입고하면 입력 내용은 두 병으로 남기고, 재고 이동량은 1,400ml로 기록한다.

### 구매와 입고를 분리한다

- 구매 문서: 발주처 원장과 금액을 보관한다.
- 입고 확정: 실제 도착한 수량만 재고에 더한다.
- 원장을 올렸다는 이유만으로 재고가 늘지 않는다.

### 재고 이동은 원장 방식으로 남긴다

입고, 판매, 제조 사용, 제조 완성, 폐기, R&D 사용, 실사 조정을 한 줄씩 기록한다. 이미 확정된 줄은 수정·삭제하지 않고 취소 줄을 추가한다.

### 같은 요청은 한 번만 반영한다

각 저장 요청에 `client_token`을 붙인다. 네트워크 오류로 사용자가 저장을 다시 눌러도 같은 토큰이면 한 번만 기록한다.

### 권한을 넓히지 않는다

- owner/editor: 입력 가능
- viewer: 조회만 가능
- 모든 표에 기존 매장 구성원 확인 규칙을 적용한다.

## 3. 추가할 표

| 표 | 역할 |
|---|---|
| `inventory_items_v2` | 품목 기본 정보와 현재 버전 |
| `unit_conversions_v2` | 병·팩·L·kg 등을 기준 단위로 바꾸는 규칙 |
| `purchase_documents_v2` | 발주처 원장, 문서번호, 날짜, 상태 |
| `purchase_lines_v2` | 구매 문서의 품목별 수량·금액 |
| `stocktake_sessions_v2` | 실사 한 회차의 시작·확정 상태 |
| `stocktake_lines_v2` | 실측 잔량과 확정 당시 장부 잔량 |
| `inventory_ledger_v2` | 모든 재고 증감의 변경 불가 원장 |

## 4. 충돌 방지

- 품목과 구매 문서에는 `version` 번호를 둔다.
- 사용자가 편집을 시작했을 때 본 버전과 저장 시점 버전이 다르면 저장하지 않고 “다른 사용자가 먼저 수정했습니다”를 표시한다.
- 전체 자료를 통째로 교체하는 `replace_store_dataset`은 새 기능에서 사용하지 않는다.
- 품목 한 건, 구매 문서 한 건, 재고 이동 한 묶음 단위로 저장한다.

## 5. 실사 기준

현재 구현에서 `실사조정.countedQuantity`는 증감량이 아니라 실제로 센 잔량이다. 새 구조도 이를 유지한다.

예: 장부 100ml, 실측 70ml이면:

- 실측 잔량: 70ml
- 조정 이동량: -30ml
- 확정 후 잔량: 70ml

같은 날 순서를 구분하기 위해 새 구조는 날짜뿐 아니라 정확한 시각도 기록한다.

## 6. 이관과 전환

1. 빈 새 표와 접근 정책만 추가한다.
2. 기존 자료를 읽어 새 표에 복사하는 변환 작업을 개발 환경에서 실행한다.
3. 품목별 잔량, 부족 상태, 사용 가능 일수, 발주 참고 결과를 비교한다.
4. 차이가 0이고 회귀 검사가 통과하면 조회 화면만 새 구조로 전환한다.
5. 입력 기능은 입고 → 실사 → 폐기/R&D → 제조 → 판매 순서로 전환한다.
6. 안정화 기간 동안 기존 자료는 삭제하지 않는다.

## 7. 이번 초안에 포함하지 않는 것

- 실제 운영 DB 적용
- 기존 자료 이관 실행
- 자동 발주 추천 산식 변경
- 사용기한 알림
- 신규 권한 체계
- 판매 취소와 제조 취소의 최종 화면
