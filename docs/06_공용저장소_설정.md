# POCO 공용 저장소 설정

## 적용 구조

- Supabase Auth: 승인된 이메일의 로그인과 세션 관리
- PostgreSQL + RLS: 같은 POCO 매장 구성원만 자료 조회
- `owner`: 전체 자료 가져오기·복원·샘플 삭제·기록 편집
- `editor`: 기록 편집
- `viewer`: 조회만 가능
- 브라우저 IndexedDB: 최근 조회 자료의 임시 캐시

## Supabase 적용

1. Supabase 프로젝트의 SQL Editor에서 `supabase/migrations/001_shared_store.sql`을 실행한다.
2. Authentication의 Site URL을 `https://poco-drinkery.vercel.app`로 설정한다.
3. Project URL과 Publishable key를 Vercel 환경 변수로 등록한다.

환경 변수 이름:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

Publishable key는 브라우저용 공개 식별키다. `service_role` 키와 데이터베이스 비밀번호는 코드, GitHub, 채팅에 올리지 않는다.

## 최초 관리자

승인 이메일은 `oran99@ecojv.com`이며 역할은 `owner`다. 로그인 화면에서 이 이메일로 계정을 만든 뒤 이메일 확인을 완료한다. 미승인 이메일은 계정을 만들더라도 매장 자료에 접근할 수 없다.

## 기존 자료 이전

1. 기존 홈페이지의 데이터 관리에서 JSON 전체 백업을 내려받는다.
2. 공용 저장소 연결 배포 후 관리자 계정으로 로그인한다.
3. 데이터 관리에서 JSON 전체 복원을 선택한다.
4. 복원 즉시 같은 매장 구성원이 같은 자료를 조회한다.
