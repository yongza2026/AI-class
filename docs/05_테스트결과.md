### 배포 중 발견·조치한 문제

- 최초 Vercel 프로젝트가 프레임워크를 `Other`로 인식해 `public` 폴더만 서비스하면서 화면 경로가 404로 응답했다.
- 프로젝트 프레임워크를 Next.js로 수정하고 빌드·출력 경로를 자동 감지로 되돌린 뒤 재배포했다.
- 재배포 후 `/`, `/sales/`, `/sales/new/`, `/profitability/`, `/expenses/`, `/inventory/`, `/inventory/new/`, `/data/`와 가상 샘플 JSON이 모두 HTTP 200으로 응답했다.
- 공개 테스트 승인을 받아 이 프로젝트의 Vercel SSO 보호만 해제했고 Git 포크 보호는 유지했다.

### 운영 배포 상호작용 오류 수정

- 2026-10-12 운영 화면은 표시되지만 파일 업로드와 데이터 입력 버튼이 반응하지 않는 문제를 확인했다.
- 원인은 CSP의 `script-src 'self'`가 Next.js 화면 초기화용 인라인 스크립트를 차단한 것이었다.
- 사용자의 보안 변경 확인 후 외부 스크립트는 계속 차단하면서 같은 사이트의 Next.js 초기화가 실행되도록 `script-src 'self' 'unsafe-inline'`로 수정해 재배포했다.
- Production의 새 브라우저 환경에서 가상 샘플 저장, 엑셀 양식 다운로드·파일 선택·검증, JSON 백업·파일 선택·복원, 판매 기록 저장을 연속 실행해 모두 통과했다.
- 재검사 결과 CSP 차단 오류와 브라우저 콘솔 오류는 각각 0건이었다.

자동 검사, GitHub 저장, 공개 Production 경로 검사를 통과했고 사용자의 확인 자동 처리 지시에 따라 EPIC 3을 완료로 표시한다.

### 직접 확인할 행동과 예상 결과

1. owner 계정으로 로그인한 뒤 왼쪽 `관리자 > 운영 비용`을 누른다. 처음에는 비용 목록 대신 `운영 비용 비밀번호 설정` 화면이 보여야 한다.
2. 8자 이상의 새 관리 비밀번호와 확인 값을 입력한다. 설정이 끝나면 기존 비용 목록이 보이고 상단에 `다시 잠그기`가 보여야 한다.
3. `다시 잠그기`를 누른다. 비용 목록이 사라지고 `운영 비용 잠금 해제` 화면으로 돌아와야 한다.
4. editor 또는 viewer 계정으로 로그인한다. 왼쪽 메뉴에 `운영 비용`이 없어야 하고 `/expenses/`를 직접 입력해도 `관리자 전용 화면입니다`가 보여야 한다.

관리 비밀번호는 아직 설정하지 않았다. 실제 owner가 첫 화면에서 직접 정하도록 비워 두었다.
