## 1. 구현 범위

- 브라우저 IndexedDB 자동 저장과 새로고침 후 유지 구조
- 프렙 카페 가상 샘플 전체 불러오기
- 공통 메뉴와 대시보드의 저장 자료 요약
- 12개 필수 시트 엑셀 양식 다운로드
- 엑셀 전체 검사, 오류 위치 표시, 확인 후 전체 교체
- JSON 전체 백업 다운로드와 검사 후 전체 복원
- 샘플·엑셀·복원의 일괄 교체 처리와 실패 시 기존 자료 보호
- 아직 구현하지 않은 EPIC 2 화면에는 다음 단계임을 명시하고 가짜 입력 기능을 제공하지 않음
