# 제품 원가 엑셀 가져오기

작성일: 2026-10-20

## 사용 순서

1. 홈페이지 왼쪽 **구매·원가**에서 **제품 원가 양식**을 내려받는다.
2. **제품목록**에 제품코드·제품명·제품분류·판매가를 입력한다. 제품코드는 `P-001`처럼 한 번 정한 값을 계속 사용한다.
3. **재료단가**에 재료명·기준단위·구매용량·VAT 제외 구매가격을 입력한다. 예: 우유 / ml / 1000 / 2500. 기존 재료를 그대로 쓸 때는 재료단가 행을 생략할 수 있지만, 시트와 열 제목은 유지한다.
4. **레시피입력**에는 제품 한 개에 쓰는 재료를 한 줄씩 입력한다. 예: `P-001 / 시그니처 라떼 / 우유 / 180 / ml`. 같은 제품의 모든 재료를 적는다. 파란 계산 칸은 직접 입력하지 않아도 된다.
5. **제품 원가 엑셀 업로드**에서 작성한 파일을 선택한다.
6. 추가·수정 건수와 제품별 원가 미리보기를 확인하고 **확인 후 저장**을 누른다. **취소**하면 저장하지 않는다.

안내 시트의 예시는 자동 등록하지 않는다. 양식의 요약·계산 칸은 참고용이며 홈페이지는 입력값으로 원가를 다시 계산한다.

## 기존 자료와 연결하는 기준

- 제품코드를 기존 메뉴 ID 또는 이전 업로드 코드와 먼저 비교한다. 연결되지 않으면 같은 제품명으로 찾는다. 기존 제품의 ID는 유지한다.
- 재료는 이름과 기준단위로 찾고 기존 재료 ID를 유지한다. 같은 이름·단위가 여러 개이면 임의로 선택하지 않고 오류로 안내한다.
- 같은 파일을 다시 올리면 제품·재료·가격·레시피가 중복 추가되지 않는다.
- 파일에 있는 제품은 전체 레시피를 가져온 내용으로 교체한다. 예전 버전은 보존해 과거 판매의 재료 차감에 계속 사용한다. 파일에 없는 제품은 유지한다.
- 가격은 매장 기준일에 적용한다. 같은 재료·적용일의 가격이 이미 있으면 갱신한다. 판매기록에 저장된 과거 원가 금액은 수정하지 않는다.
- 품목 설정과 단가·레시피만 반영한다. 초기재고·입고·폐기·판매·제조 배치 수량은 생성하거나 변경하지 않는다.

## 오류 안내

`.xlsx` 10MB 이하 파일을 지원한다. 빈 가격과 명시한 0원은 구분한다. 제품·재료 중복, 재료 단위 불일치, 누락된 제품·재료, 0 이하 사용량, 잘못된 가격, 제품별 레시피 누락이 있으면 시트와 행을 표시하고 전체 저장을 중단한다. 조회 전용 사용자는 업로드할 수 없다. 저장 실패 시 성공 메시지를 표시하지 않으며 다시 시도할 수 있다.

## 구현 및 확인 범위

기존 데이터 저장 방식과 원가 계산식을 재사용한다. 제품 코드가 JSON 백업·복원 시 보존되도록 메뉴의 추가 필드도 유지한다. 운영 DB와 연결되지 않은 로컬 환경에서만 저장 검사를 수행했다. 운영 배포와 운영 DB 저장 검사는 수행하지 않았다.
